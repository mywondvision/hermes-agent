# Первичная квалификация провайдера на Linux

Кандидат `2c1a4c40`. Нативная квалификация на новой виртуальной машине открыта.

Сценарий проверяет клиент с синтетической подпиской в отдельной службе Linux. Служба запускает тесты закреплённым интерпретатором, под выделенной учётной записью, с изолированной сетью и ограничениями памяти, числа процессов и времени работы. При остановке служба должна завершить всю свою контрольную группу.

Для приёмки оператор сопоставляет идентификатор запуска службы с записью привязки и проверяет одноразовый идентификатор запроса. Требуются код выхода 0, два прошедших теста и ноль пропусков. Записи запроса, остановки и наблюдения за процессами должны относиться к одной попытке. Если ядро не позволяет подтвердить состояние процессов в группе, квалификация остаётся открытой.

Для пилота с реальным провайдером дополнительно требуются отдельная учётная запись клиента, защищённая передача учётных данных и проверка политики рабочей области до отправки запроса.
