## Восстановление

Три ветки в fork имеют общий префикс `checkpoint/symphony-20261122-final`. Координатору соответствует сама ветка, исполнителям — суффиксы `-windows` и `-linux`. В каждой ветке этот файл находится по пути `docs/handoffs/symphony-20261122/RESUME.md`. Публичные коммиты являются снимками для передачи работы; их SHA отличаются от исходных коммитов в таблице.

В общей копии каталог `.artifacts/handoff-20261122-final` содержит частный архив документов, Git bundle исходных версий и манифест с контрольными суммами. В новой сессии на том же компьютере сначала сверьте HEAD и локальные изменения. Для восстановления в новом клоне используйте пустой каталог, сохранённый bundle и существующую базу истории, указанную в локальной инструкции. Исходные рабочие копии и их индексы нужны для продолжения параллельной работы.
