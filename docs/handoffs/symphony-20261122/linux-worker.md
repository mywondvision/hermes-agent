# Квалификация тестового исполнителя Linux

Кандидат `2c1a4c40`. Результат нативного прогона на новой виртуальной машине ещё предстоит получить.

Для проверки воспроизводимости образ собирают дважды из одних входов в отдельных каталогах и сравнивают SHA-256 образа и манифеста. Сборка проверяет состав файлов, владельцев и права доступа. При запуске тестовой площадки исполнитель связывает конкретную попытку с отдельным профилем, клоном и разрешением на исполнение. Отпечаток манифеста сверяется с независимо закреплённым значением.

Перед исполнением зонд проверяет полный состав внутреннего окружения. Тестовая программа подтверждает, что запрет сети включён. Расхождение требует разбора на гостевой машине.

В сценарии записи оператор проверяет неизменность исходного клона и связь отпечатка патча с результатом проверки той же попытки. В сценарии с потомками наблюдатель фиксирует корневой процесс, ребёнка и внука. Проверка остановки требует наблюдения за исходной контрольной группой. После смены владельца журнал должен позволять прочитать результат прежней попытки.

Сценарий ожидания длится до 90 секунд. Для таймаута, отмены владельцем и их одновременного наступления используют отдельные попытки. В каждой сверяют записанную причину, число фактических отмен, результат остановки и состояние резерва.
