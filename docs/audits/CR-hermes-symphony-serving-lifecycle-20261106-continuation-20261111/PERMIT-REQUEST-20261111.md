# Запрос допуска на следующий шаг (не является допуском)

Дата: 2026-11-11. CR: `docs/change-requests/CR-hermes-symphony-serving-lifecycle-20261106-continuation-20261111.md`.
Этот документ перечисляет, что владелец должен назвать точно, прежде чем serving lifecycle сможет запустить
настоящий driver. Пока ни одна строка не заполнена владельцем, всё ниже остаётся **HOLD**.

## Что уже закрыто без модели

- create → Job: процесс рождается внутри kill-on-close Job (`PROC_THREAD_ATTRIBUTE_JOB_LIST`), отдельного шага
  назначения больше нет;
- восстановление: преемник записывает наблюдение о незавершённом create и не запускает повторно;
- квалификация: transport и launcher не собираются без совпадающей `QualificationRecord`.

Статус доказательств — в `RESULT-20261111.md` рядом с этим файлом.

## Что должен назвать владелец

| Параметр | Требуемая точность |
|---|---|
| Driver | точная ревизия kit (`kit_revision`), абсолютный путь и SHA-256 исполняемого файла |
| Модель и effort | одно точное значение каждого; без «по умолчанию» |
| Среда | ссылка на конкретное дочернее окружение профиля (`environment_ref`); ambient `os.environ` не допускается |
| Профиль и namespace | канонический `profile_home`, `namespace`, `scheduler_id` |
| Issuers | точный упорядоченный список `issuer_refs` и production approval source |
| Попытка | одна попытка, retries=0, с бюджетом времени и расходов |
| Cancel | отдельный допуск на native/global cancel и настоящий stop с собственными доказательствами |

## Что должно быть исправлено до запуска настоящего driver

Независимое ревью (2026-11-11) оставило открытым одно существенное замечание: Job Object создаётся с именем и
DACL по умолчанию, поэтому любой процесс того же пользователя, включая дерево воркера, может открыть его по имени
и, удерживая хендл, пережить смерть owner. Для синтетического воркера это не действует; для driver, исполняющего
команды модели, — действует. Требуется отдельный слайс: закрытый DACL на Job, передача хендла observer через
`DuplicateHandle`, `ERROR_ACCESS_DENIED` в `job_present` трактуется как «есть», и отдельный native-допуск на его
проверку.

## Что остаётся запрещено до допуска

Запуск CodexDriver и моделей, native/global cancel, release резервирования, настоящий stop, установка transport
в S3, deploy, merge, микрофон, платные ресурсы, повторный native-проход тестов.
