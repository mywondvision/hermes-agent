## Вывод для дизайна

- Запрет на каталоге без распространения закрывает чтение **по пути** (проход проверяется), но не открытие **по
  идентификатору файла**: у такого открытия нет пути и нет проверки прохода. Идентификаторы NTFS перебираемы.
  Защита настоящих корней в предложенном виде недостаточна.
- Оставшиеся варианты (решение владельца): наследуемый запрет на конкретных каталогах секретов (переписывает DACL
  их поддерева — изменение хоста шире одной записи); список разрешений вместо запретов (LPAC, отдельный CR);
  другой субъект (отдельная учётная запись или VM).
- Остальное подтверждено: токен без привилегий стартует, запись вне своей попытки закрыта, чтение по пути и
  реестр закрываются запретом для SID класса, откат запретов точный.
