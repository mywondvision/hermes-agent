## Отклонения стенда

- Стенд записал `stop = PROBE_NOT_FIRST`: его фильтр принял за «первую команду» сообщение агента со словом
  «command». Журнал показывает, что зонд был первой командой. Фильтр исправлен (`item.type == command_execution`).
- Пост-обработка (capture и проверка) выполнена отдельным скриптом после остановки стенда, без нового вызова
  модели; первая попытка проверки применила patch по относительному пути и не нашла файл — повторена с абсолютным.

## Что это значит

- Схема работает: Codex по подписке ChatGPT, файл авторизации в отдельном `CODEX_HOME`, MXC с профилем
  «только своя попытка», чистое окружение — задача выполнена без участия владельца, граница подтверждена изнутри.
- Без запуска тестов Codex пропускает платформенные ошибки. Для следующих задач стоит дать ему проверку внутри
  песочницы (интерпретатор тестов только на чтение) или оставить автоматическую проверку owner-стороной и цикл
  «исправь по отчёту».
- Не проверено: MCP, web search, коннекторы (выключены); процессы того же пользователя.

## Решения владельца

1. Принять результат (patch от Codex + однострочное исправление) в код: применить к рабочей копии и закоммитить в
   приватную и публичную ветки — или оставить как доказательство пилота.
2. Следующий шаг автономности: разрешить Codex запускать fixture-тесты в песочнице (чтение тестового окружения) и
   один цикл исправления.
