# Промежуточный результат: native-проход MXC (2026-11-14)

(допуск владельца: «ok, один native-проход MXC»).

**Проход не дошёл до песочницы: `1 files, 0 passed, 1 failed`, 909 с.** Тест упал на первом шаге — снимке хоста
(H1 «до»), ещё до создания приманок, ключа реестра, временного `CODEX_HOME` и до запуска Codex. MXC, `codex
sandbox` и зонд не запускались; о песочнице этот проход ничего не говорит. Повтор не выполнялся.

Ресурсы перед стартом: RAM 1,38 ГБ, файл подкачки 9,3 ГБ, D: 663,6 ГБ. Исходники до и после совпадают
(`source_unchanged: true`); тестовых ключей `SymphonySmoke-*` нет.

## Причины (дефекты стенда, исправлены, проверены без запуска песочницы)

1. `powershell` выводит имена локальных учётных записей в OEM-кодировке; чтение вывода как UTF-8 упало
   (`UnicodeDecodeError`), снимок получил `None`. Теперь вывод сравнивается по SHA-256 байтов; снимок хоста
   дважды подряд даёт одинаковый результат (89 с на два снимка).
2. Поток, ожидающий подключение к тестовому слушателю, был запущен до `try` и без таймаута; после падения он не
   дал процессу завершиться, файл тестов был убит по таймауту 900 с. Теперь слушатель создаётся после снимка, у
   `accept` таймаут 300 с, поток стартует внутри `try` и закрывается в `finally`.
