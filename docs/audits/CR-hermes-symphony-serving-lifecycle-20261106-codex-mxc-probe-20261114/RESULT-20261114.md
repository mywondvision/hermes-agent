## Что это значит для пилота

- Обход через file ID, найденный в собственной схеме, в MXC не работает: проверка идёт на самом объекте.
- Изоляция команд MXC подходит, но **клиенту Codex нельзя передавать секреты через окружение**: он отдаёт своё
  окружение командам. Значит, авторизация модели в пилоте — только файлом в `CODEX_HOME` (каталог не входит в
  читаемые пути профиля), окружение клиента — без ключей. Отдельно не проверено, фильтрует ли окружение
  `shell_environment_policy` в `codex exec`; на это полагаться нельзя до проверки.
- Не проверялись: MCP, web search, коннекторы и прочие возможности клиента; процессы того же пользователя не
  изолированы.
